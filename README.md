# Sistema de Backlog em C

Projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas, com o objetivo de praticar lógica de programação e os fundamentos da linguagem C.

## Sobre o projeto

O programa recebe a quantidade de chamados pendentes e classifica a situação do backlog.

Atualmente, a lógica utilizada é:

- Mais de 10 chamados: backlog alto
- 10 chamados ou menos: backlog controlado

## Conceitos praticados

Neste projeto estou praticando:

- Variáveis em C
- Entrada de dados com `scanf`
- Saída de dados com `printf`
- Estruturas condicionais `if` e `else`
- Operadores relacionais
- Compilação com GCC
- Controle de versão com Git
- Publicação de projetos no GitHub

## Como executar

Compile o programa:

```bash
gcc backlog.c -o backlog
